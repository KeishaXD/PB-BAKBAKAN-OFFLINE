# PB BAKBAKAN OFFLINE

PB BAKBAKAN OFFLINE adalah paket server **Point Blank Offline** yang memungkinkan pemain menjalankan game Point Blank secara lokal tanpa koneksi internet.

Project ini dibuat untuk tujuan **testing, pembelajaran, dan nostalgia bermain Point Blank secara offline**.

---

## ✨ Fitur

- Menjalankan server Point Blank secara **offline**
- Script kontrol server sederhana
- Mode permainan:
  - Practice
  - Zombie Mode
- Tidak membutuhkan koneksi internet
- Mudah dijalankan melalui file `.bat`

---

## ⚠️ Catatan Penting

- Mode offline **hanya bekerja untuk:**
  - Practice
  - Zombie Mode
- Untuk pangkat **di atas GM**, kemungkinan **tidak dapat bermain**.
- Project ini dibuat hanya untuk **keperluan edukasi dan eksperimen**.

## 🚀 Cara Menjalankan

1. Download repository ini: git clone https://github.com/KeishaXD/PB-BAKBAKAN-OFFLINE.git atau download dalam bentuk **ZIP**.

2. Extract file jika menggunakan ZIP.

3. Jalankan server dengan file: StartServer.bat

4. Tunggu sampai semua service server berjalan.

5. Jalankan client **Point Blank** dan login ke server lokal.

---

## 🖥️ Requirements

- Windows 7 / 10 / 11
- .NET Framework (jika dibutuhkan oleh server tools)
- Client Point Blank yang kompatibel
- RAM minimal 4GB (direkomendasikan)

---

## 🛠️ Troubleshooting

### Server tidak bisa start

- Pastikan semua file server sudah lengkap
- Jalankan `.bat` sebagai **Administrator**

### Tidak bisa login

- Pastikan semua service server sudah **Running**
- Periksa konfigurasi IP server
